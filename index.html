README.md - Hacker Typer Simulator

Deskripsi Proyek

Hacker Typer Simulator adalah web app interaktif bergaya terminal retro yang mensimulasikan pengetikan kode tingkat lanjut secara otomatis. Sangat ideal digunakan sebagai properti film pendek, sarana lelucon (prank) kepada teman, atau sekadar membuat Anda terlihat super sibuk di kantor maupun kelas.

Fitur Utama & Pintasan Keyboard

  • Ketikan Acak Otomatis: Tekan tombol apa saja pada keyboard untuk menghasilkan barisan kode kompleks (C++, Python kernel, Enkripsi AES) sebanyak 3-5 karakter per ketukan.
  • Tombol F11: Membuka petunjuk layar penuh browser.
  • Tekan tombol Alt 3 kali beruntun: Memicu popup rahasia ACCESS GRANTED dengan efek glitch cyberpunk.
  • Tekan tombol Caps Lock 3 kali beruntun: Memicu peringatan bahaya darurat ACCESS DENIED berwarna merah menyala.
  • Tombol Esc: Menutup modal peringatan aktif dan mengembalikan fokus ke konsol.

Panduan Deploy di GitHub Pages

  1. Buat repository publik baru di GitHub (misalnya: hacker-typer-clone).
  2. Unggah file kode sumber ini dan beri nama index.html.
  3. Masuk ke menu Settings repository Anda di GitHub.
  4. Navigasi ke tab Pages pada sidebar kiri.
  5. Pada bagian Build and deployment, pilih Branch ke main (atau master) dan folder / (root), lalu klik Save.
  6. Tunggu beberapa saat, website simulator Anda kini dapat diakses secara publik melalui link GitHub Pages!
